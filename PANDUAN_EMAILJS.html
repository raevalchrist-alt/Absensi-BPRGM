📧 Panduan Setup EmailJS

Agar foto absensi terkirim otomatis ke email HRD — 100% gratis, tanpa server

1

Daftar Akun EmailJS Gratis

Buka emailjs.com → klik Sign Up Free

  • Daftar pakai Google atau email biasa
  • Plan gratis: 200 email/bulan — cukup untuk ~6-7 karyawan absensi 2x/hari
  • Tidak butuh kartu kredit
2

Tambah Email Service (Gmail)

Setelah login → klik Email Services di sidebar → Add New Service

  • Pilih Gmail
  • Klik Connect Account → login dengan akun Gmail HRD
  • Beri nama service, misal: absensi_kantor
  • Klik Create Service
  • Catat Service ID yang muncul (contoh: service_abc123)
⚠️ Gunakan Gmail khusus/dummy untuk server, bukan akun Gmail pribadi HRD. Email dari-nya akan jadi akun ini.
3

Buat Template Email

Klik Email Templates → Create New Template

Isi template seperti berikut (copy-paste langsung):

Subject:

{{subject}}

Body (HTML):

✅ Foto hanya dari live camera (tidak ada opsi upload) — menjamin autentisitas

💡 Fitur keamanan:

  • ✅ Watermark: nama, waktu (jam/tanggal), lokasi GPS tercetak di foto
  • ✅ EXIF GPS Verification: validasi foto GPS vs device GPS (cegah mock GPS)
  • ✅ Geo-Fence: pastikan absensi hanya di wilayah kantor
  • ✅ Anti-Spoofing: deteksi akurasi GPS aneh dan kecepatan impossible

To Email: isi dengan {{to_email}}

Klik Save → catat Template ID (contoh: template_xyz789)

4

Ambil Public Key

Klik nama akun di pojok kanan atas → Account → tab General

Copy nilai Public Key (contoh: aBcDeFgHiJkLmNoP)

5

Isi di index.html

Buka index.html, cari bagian ini dan isi 3 nilai:

// KONFIGURASI EMAILJS — ISI 3 NILAI INI const EJS_PUBLIC_KEY = 'aBcDeFgHiJkLmNoP'; // dari Account > API Keys const EJS_SERVICE_ID = 'service_abc123'; // dari Email Services const EJS_TEMPLATE_ID = 'template_xyz789'; // dari Email Templates

Simpan → push ke GitHub → selesai! ✅

📊 Kapasitas Plan Gratis

  • 200 email/bulan gratis — cukup untuk ~10 karyawan (2x absensi/hari × 22 hari kerja = 440, kurang)
  • Jika karyawan lebih dari 3-4 orang, upgrade ke plan Personal Rp 50rb/bln (1.000 email/bln)
  • Atau: buat 2-3 akun EmailJS berbeda dan rotasi (masing-masing 200/bln = 600/bln total)
  • Alternatif lain: pakai Resend.com (3.000 email/bln gratis) — butuh domain sendiri

🎉 Selesai! Tanpa Bayar Server

Karyawan foto → klik Kirim → email + foto langsung masuk ke inbox HRD.
Tidak perlu VPS, tidak perlu backend, tidak perlu bayar apapun.
